# task6
K-Nearest Neighbors (KNN) Classification

# Objective
Implement and understand the K-Nearest Neighbors algorithm using Scikit-learn for a classification task.
# Tools Used
- Python
- Pandas
- Scikit-learn
- Matplotlib
- Seaborn (optional, for better plots)

 Steps
1. Load and normalize the dataset.
2. Split into train/test sets.
3. Apply `KNeighborsClassifier` from Scikit-learn.
4. Evaluate using accuracy and confusion matrix.
5. Visualize decision boundaries for different values of K.

##  Results
- Model accuracy with different K values.
- Confusion matrix visualization.
- Decision boundary plots.
